# Number Guessing Game in Java

A simple console-based number guessing game developed using Java.

## Features
- Random number generation between 1 and 100
- Limited attempts to guess the number
- Feedback to help the player guess correctly

## Technologies Used
- Java
- Scanner
- Random number generation

## How to Run

1. Install the Java JDK.
2. Clone or download this repository.
3. Open the project folder in the terminal.
4. Compile the program:

   javac NumberGuessing.java

5. Run the program:

   java NumberGuessing
